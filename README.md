# Whoxa Admin Panel

Whoxa WhatsApp Clone - Modern React + TypeScript + Vite Admin Dashboard.

## Deploying to Vercel

1. Import this repository in [Vercel](https://vercel.com).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. In **Environment Variables**, add:
   - `VITE_API_URL`: Your backend API base URL (e.g. `https://specifications-board-shape-strange.trycloudflare.com` or your production backend domain)
   - `VITE_PRODUCT_TYPE`: `client`
6. Click **Deploy**!

`vercel.json` is already included for automatic Single Page Application (SPA) routing.
